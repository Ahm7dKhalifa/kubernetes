2 Interactive Port Plugin

Layer 1: Entrypoint

NodePort (30001)

The public IP of your server listens here. This maps external traffic into the cluster network.

spec.ports[0].nodePort

Layer 2: Load Balancer

Service Port (80)

The virtual internal IP of the Service. Other pods in the cluster use this port to talk to this app.

Layer 3: Destination

TargetPort (8080)

The specific port where the containerized process (e.g. Nginx, Go, Node.js) is listening.

3. Full Application Manifests

apiVersion: v1
kind: Service
metadata:
  name: frontend-svc
spec:
  type: NodePort
  ports:
  - port: 80           # [STEP 2] Internal Service Port
    targetPort: 8080   # [STEP 3] Where the code listens
    nodePort: 30001    # [STEP 1] External Entrypoint
  selector:
    app: frontend
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: frontend
spec:
  replicas: 2
  template:
    spec:
      containers:
      - name: nginx-container
        image: nginx:1.23
        ports:
        - containerPort: 8080
apiVersion: v1
kind: Service
metadata:
  name: backend-svc
spec:
  type: ClusterIP
  ports:
  - port: 9000
    targetPort: 5000
  selector:
    app: backend
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: backend
spec:
  replicas: 5
  template:
    spec:
      containers:
      - name: python-api
        image: python:3.9-slim
        ports:
        - containerPort: 5000
